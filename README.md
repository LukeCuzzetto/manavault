# DECK//ENGINE

**Construct. Analyze. Refine.**

DECK//ENGINE is a Go and PostgreSQL backend API for building, managing, and analyzing Magic: The Gathering collections and decklists.

## Project goals

- Build a production-style REST API in Go
- Store users, collections, and decklists in PostgreSQL
- Integrate with the Scryfall API for card data and artwork
- Analyze deck composition and statistics
- Practise testing, authentication, migrations, Docker, CI, and deployment
- Document the architecture and development process as a portfolio project

## Status

Archived.

DECK//ENGINE was an early learning-focused backend project used to build

foundations in Go HTTP services, PostgreSQL, testing, middleware, database

migrations, configuration, and application lifecycle management.

Development was intentionally stopped at the backend-foundation stage in August 2026 when the project's scope evolved into SentinelOps, a mission-operations/backend systems project focused on remote physical systems.
